# GAXEL — Organização Interna

Pasta de trabalho para compilar as informações da marca antes de lançar no Notion.

- `identidade/` — identidade visual oficial (cores, tipografia, direção visual), extraída do `GAXEL_Brand_Board.pdf`.
- `produtos/` — uma ficha técnica por peça (distinta base, custos, precificação, break-even, status no fluxo criativo). Comece por `produtos/README.md`.

O fluxo completo (7 fases, estrutura de pastas Drive + Notion, esquemas de banco de dados) está no blueprint publicado como artifact na conversa — esta pasta é o rascunho local que alimenta aquele sistema.
