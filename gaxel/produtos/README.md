# Produtos — Fichas Técnicas

Um documento por peça. É o rascunho de trabalho que depois vira uma linha no banco "Produtos" do Notion (ver blueprint publicado no chat — seção "Criar Produtos").

## Como usar

1. Duplique `_MODELO-ficha-tecnica.md`.
2. Renomeie para `CODIGO-nome-do-produto.md` — minúsculo, com hífen (ex.: `CO-001-colar-perugia.md`).
3. Preencha as 12 seções. Nem tudo precisa estar completo no dia 1 — a seção 11 (Status no Fluxo Criativo) mostra até onde a peça já chegou.
4. Quando a seção 6 (Precificação) estiver fechada, a peça está pronta para virar uma linha no Notion.
5. Se a peça pertence a uma coleção nomeada, crie uma subpasta `colecao-<nome>/` (ex.: `colecao-equinox/`) e coloque a ficha lá dentro, com um `README.md` mapeando todas as peças da coleção — é o que abre automaticamente ao navegar pela pasta no GitHub.

## Convenção de código

| Prefixo | Categoria |
|---|---|
| BR | Pulseira / Bracelete |
| CO | Colar |
| AN | Anel |
| BC | Brinco |

Ajuste se você já usa outra convenção — o importante é ser consistente daqui pra frente.

## Coleções
